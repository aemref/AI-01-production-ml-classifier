# AI-01 Production ML Classifier

A machine learning classification project for practicing Python, machine learning, and production engineering.

## Focus

AI/ML and production engineering.

## Project Goals

- Measure baseline Python skills
- Measure baseline machine learning skills
- Build a simple classification pipeline
- Add automated tests
- Set up continuous integration
- Track measurable progress over time

## Repository Structure

```text
src/       Source code
tests/     Unit tests
data/      Dataset files
docs/      Documentation
.github/   GitHub Actions and repository configuration
```

## Local Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m pytest
python src/train.py --data data/sample.csv
```
